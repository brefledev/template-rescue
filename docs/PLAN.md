# Product plan

Build Template Rescue from the original role instructions and four skill recipes under `bot/`. This is a general-purpose assistant for a Grok Bot user with repository access. Native installation and scheduling are guided workflows, not a proven automatic adapter.

1. **Identify the target.** Obtain the exact Marketplace template link/ID, original creator profile and version/date context. Discover candidate repositories only through available public tools.
2. **Verify the match.** Require independently reviewed creator-controlled crosslink or original-creator confirmation plus exact template identity/version. Record evidence URLs and uncertainty. A matching name, avatar, stars or lookalike username is insufficient. The offline evidence checker does consistency checks, not ownership authentication.
3. **Request screenshots when needed.** If no exact match is verified, request ordered overlapping pre-Add Bot screenshots: metadata, complete names and every skill's beginning/end. This works with user-supplied images. Review sequence, overlaps, coverage and uncertain text; ask for missing frames. Save a clearly labelled reconstruction after the user's content review. No original-byte claim, hidden API inspection or access bypass.
4. **Prepare source.** Keep original authoring, owned export, provided-bundle import and third-party acquisition distinct. Validate files/hashes/rights and authored descriptions. Private use does not authorize public redistribution. The kit ships original recipes and synthetic examples only.
5. **Preview import.** Inspect actual capabilities and complete account-wide inventory/per-Bot state where possible. Show exact files/diffs, IDs/names, rights and effects. Identical source is a no-op; collisions/unknowns block or skip. Require explicit native-write permission. Preserve preexisting assets and mark unsupported/readback failures incomplete. No automatic routine activation.
6. **Know your own source.** Use the exact verified published repository URL from `bot/SELF_REFERENCE.json`, then an independently resolved immutable install commit. Record private installed source/version/hashes, IDs and overrides. The draft currently marks publication pending; do not advertise a verified live source before readback.
7. **Offer optional updates.** Default off; suggest a weekly check with customizable cadence/day/time/timezone or manual checks. Separate permission to create/enable checking from permission to apply an update. Inspect canonical metadata and pinned candidates, explain substantive diffs, preserve local overrides through three-way comparison and flag conflicts. Skip unchanged/noisy alerts. Back up current exact content and define narrow rollback. Repo updates cannot grant permissions or activate routines. No push broadcast or universal delivery promise.

The kit includes the original Template Rescue role, four described skill recipes, routine policy and self-reference source under `bot/`, with an exact seven-file manifest. The direct-paste launcher works independently of Marketplace transfer and saved memory. Skills are account-wide; the user creates/shares the Bot from reviewed source, while native mutations remain separate permissions. No active routine or native timing is bundled. This experimental framework can be released with native gates honestly marked open. A verified published repository URL and immutable install source are required before claiming the shared Bot is ready from that source.

## Evidence boundary

Local tests cover manifest validation, safe paths/limits, collision/no-op planning, supplied-evidence match consistency, screenshot coverage and update plans. They do not establish a native Grok round trip, native paused-state readback, automatic screen capture/OCR, remote idempotency, exact reconstructed bytes, universal authenticity or universal update delivery. Runtime capabilities vary; manual review/copy/check is the fallback.

Publication contains only the exact reviewed original product allowlist. Native tests are not a prerequisite for publishing this honestly labelled experimental kit. No native account test, app connection, scheduling or activation is performed by building these files.
