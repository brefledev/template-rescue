# Patch Cassidy / Verify template source

Identify the exact Marketplace template link/ID, original creator profile and version/date context. Discover public repository candidates only with tools actually available. Require an independently reviewed creator-controlled crosslink or original-creator confirmation that points to the exact repository and exact template/version. Record evidence URLs, what was read and verified, and remaining uncertainty.

Name/avatar/star count/GitHub username similarity and a repository's own assertion are insufficient. A source repository with an ambiguous version is not a verified exact match. Do not promise an automatic authenticity guarantee. The offline match checker validates supplied evidence consistency; it does not fetch or authenticate that evidence.

If none is verified, keep the source match unverified. For an imported bot, use audit-imported-bot.md to obtain its own full skills by direct messaging and approved file export. Request screenshots only as a last resort when export cannot supply the needed text and no readable original source is available. Authenticity and redistribution rights are separate. Do not publish third-party bodies without established rights.
